# Hokuto100retsuken Tap

## How do I install these formulae?

`brew install hokuto100retsuken/tap/<formula>`

Or `brew tap hokuto100retsuken/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "hokuto100retsuken/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
